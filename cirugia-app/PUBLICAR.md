# Publicar la app

Subir estos archivos juntos al sitio:

- `index.html`
- `styles.css`
- `app.js`
- `assets/membrete.jpg`
- `assets/firma.png`
- `assets/pie-membretado.png`

En GitHub Pages deben quedar en la raiz del repositorio, conservando la carpeta `assets`.

Despues de publicarla, abrir la liga del sitio y probar:

1. Capturar nombre, fecha de nacimiento, procedimiento, diagnostico, fecha y hora de ingreso.
2. Revisar que la hoja quede en una sola carta y no corte el pie membretado.
3. Probar `Descargar PDF`.
4. Probar `WhatsApp / compartir` y `Correo PDF`.

Nota: el envio por correo abre el cliente de correo con el destinatario `drpablovidal@gmail.com`. Para adjuntar el PDF automaticamente sin tocar nada haria falta un servidor o servicio de correo conectado.
